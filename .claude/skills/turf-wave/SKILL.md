# TURF Wave

Use this skill to create or update TURF waves.

## Wave requirements

- Define the retail-territory question being answered.
- Identify data sources and their license/source-policy status.
- Separate inferred public footprint claims from official corporate territories.
- Break the wave into small pulses with validation expectations.
- Record non-goals and shared-system boundaries.
