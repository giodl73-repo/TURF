# TURF Research

This directory holds research modules that connect TURF's public-footprint
evidence to longer historical patterns of settlement, service geography, and
commercial terrain.

The modules are not source-free essays. Each module must cite repo-generated
reports, checked CSVs, public-source notes, and any outside historical sources
it relies on.

## Active Tracks

- `tracks/A-lineage/` - historical-lineage modules that compare older
  settlement functions with modern public institutions and retail footprint
  evidence.

## Module Contract

Each module should include:

- a thesis section,
- a lineage section,
- a modern TURF evidence section,
- a source policy section,
- a claim boundary section,
- at least one reusable lineage table with:
  `historical function -> modern institution -> TURF evidence -> example fields`.

## Boundaries

Research modules may use historical analogies to explain observed terrain
patterns. They must not claim that commercial footprints define culture,
individual behavior, protected traits, official corporate territories, or
formal civic boundaries unless those claims are directly sourced.
