# A.3 Port / Landing / Depot / Corridor

## Thesis

Ports, ferry landings, depots, airports, intermodal nodes, and highway corridors
can function as modern movement-enclave terrain inside TURF when they
concentrate transfer, mobility, car-trip, food-service, civic, and commercial
service evidence.

This is a functional analogy. It is not a claim about port authority
boundaries, freight flows, ferry catchments, commuter catchments, route choice,
trip purpose, or direct historical continuity.
