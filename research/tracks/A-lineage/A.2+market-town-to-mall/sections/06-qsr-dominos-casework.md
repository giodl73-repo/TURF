## Read

The Kingston prompt is useful because it exposes a category boundary problem.
The first QSR fixture covers McDonald's, Burger King, Wendy's, and Taco Bell.
That is enough to compare a baseline national QSR grid, but it is not enough to
describe all food-service or pizza-delivery provisioning.

In the current Puget Sound QSR report, Kingston is a single-brand QSR node in
the four-brand fixture. Domino's official location evidence adds a current
Kingston pizza/carryout node at 8208 NE State Hwy 104 Suite 107. That does not
turn Kingston into a dense QSR grid, and it does not prove a delivery area. It
does show that "single-brand in the four-brand fixture" is not the same thing
as "food-service absent."

## Case Classes

Kingston / Bainbridge ferry-side selectivity:
single-brand evidence in the four-brand QSR layer should be treated as
selective provisioning terrain, not white space.

Bremerton / Poulsbo / Silverdale / Port Orchard:
four-brand QSR evidence and close opposite-brand spacing show dense same-side
provisioning grids.

Atlanta:
QSR continuity across rings shows a different metro form, where food-service
coverage is contested from core to exurb rather than split by ferry-side
selectivity.

Arlington / Grand Prairie:
QSR, auto parts, and gas/convenience are all dense, making the field a combined
daily-trip and auto-service grid. This belongs near the future port / depot /
highway-node branch.

## Boundary

Domino's-style casework is chain presence evidence. It is not a delivery-area
guarantee, franchise-territory map, customer-behavior claim, service-adequacy
claim, or drive-time catchment.

The next useful build is a pizza-delivery sidecar contract that treats Domino's
as a provisioning layer alongside, but not interchangeable with, the four-brand
QSR fixture.
