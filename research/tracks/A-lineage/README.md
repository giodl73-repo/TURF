# Track A: Lineage

Track A studies how older settlement functions reappear as modern public
infrastructure and commercial-footprint signals.

The track treats historical institutions as analogues, not one-to-one
equivalents. Each module separates:

- formal boundary,
- public infrastructure layer,
- commercial footprint,
- analogy,
- future model hypothesis.

## Sequence

1. `A.1+postal-parish/` - complete. Postal/address infrastructure as a modern
   parish-style addressability layer.
2. `A.1b+minimum-postal-parish/` - scaffolded. Sparse postal/addressability
   nodes as candidate minimum enclaves.
3. `A.2+market-town-to-mall/` - town/port/depot/highway spine matrix added.
   Malls, retail complexes, grocery/pharmacy grids, QSR clusters,
   highway-service nodes, and mass-retail anchors as modern market-center
   terrain.
4. `A.3+port-landing-depot-corridor/` - reviewed movement-node module closed.
   Ports, ferry landings, depots, airport edges, intermodal nodes, and highway
   corridors as modern movement-enclave terrain.
5. `A.4+guild-quarter-to-professional-services/` - service-quarter depth
   synthesized. Banks, credit unions, insurance, tax prep,
   legal/accounting/notary offices, real-estate offices, loan/mortgage offices,
   and local professional services as modern public-facing service-quarter
   terrain.

Future modules should be created only when the prior module has enough evidence
quality and role review to justify the next scaffold.

## Next Gate

Pause post-office expansion as the main workstream. A.1b now functions as a
method proving ground for claim boundaries, exclusions, and scoped-frame
discipline.

The selected claim surface is current-enclave stack typology, and the first
atlas is publication-ready as `current-enclave-atlas-publication-package.md`.
No additional source closeout is required for that typology claim. The next
active gate is an explicit pivot to one deferred claim surface only if the
claim changes.
Consulting and generic business-service rows remain deferred by default.
Domino's-style coverage, QSR clusters, gas/convenience, auto-parts, ferry route
context, ferry terminal, transit-center, lodging, and corridor-service evidence
should be studied as town/provisioning and port/depot/highway-node terrain, not
as a post-office-only problem.

The Phase 2 pivot is ferry-side full-stack comparison, starting with Kingston
WA. Kingston A.4 service-quarter scoring and bounded provisioning broadening
are complete with caveats, and the ferry movement layer is bounded to route and
terminal-cluster evidence. Kitsap Mall / Silverdale and Bremerton WA are the
selected ferry-side closeout controls. CEP-005 is promoted from design-only to
packet-ready-with-caveat, but not to clean full-stack. This is a depth-first
central-spine lane, not a renewed 50-state post-office breadth push.
