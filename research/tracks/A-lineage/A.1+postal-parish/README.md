# A.1 Postal Parish

## Thesis

Postal and address infrastructure functions like a modern parish-style layer
for addressability and everyday service geography in the United States.

This is an analogy about institutional addressability. It is not a claim that
ZIP Codes, ZCTAs, post offices, churches, cities, neighborhoods, retail chains,
or Census geographies are interchangeable.
