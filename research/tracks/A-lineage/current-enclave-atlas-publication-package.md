# Current Enclave Atlas Publication Package

This package collects the first Track A current-enclave atlas around the
selected claim surface: current-enclave stack typology.

## Publication Claim

Track A can classify selected current-enclave fields by stack role:

- clean full stack,
- highway-service full stack with caveat,
- corridor-service partial movement,
- depot/intermodal plus service profile gap,
- ferry-side design-only contrast,
- light-control service-quarter contrast.

No additional source closeout is required for this typology claim. Additional
truck-stop, freight, loan/mortgage, ferry-side service-quarter, or light-control
upgrade work is deferred unless the claim surface changes.

## Release Note

First Track A current-enclave atlas packaged. The atlas translates the central
spine into six packet roles and selects current-enclave stack typology as the
active claim surface. It explicitly defers truck-stop coverage, freight volume,
lender-edge expansion, Kingston full-stack promotion, Kitsap full-stack
upgrade, broad post-office expansion, national category expansion, consulting,
and generic business-service rows.

## Claim Boundary

This package supports observable current-enclave stack classification only. It
does not establish official boundaries, direct historical descent, lived
identity, demographics, resident identity, service adequacy, catchments,
demand, traffic models, spending, freight flow, truck counts, trip purpose,
transaction volume, professional quality, service absence, or individual
behavior.
