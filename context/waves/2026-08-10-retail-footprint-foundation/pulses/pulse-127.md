# Pulse 127: Fifth Metro Scale Decision

## Intent

Decide whether TURF should keep resolving Atlanta source gates or add a fifth
metro for type discovery.

## Work

- Reviewed the current cross-metro type-discovery profile.
- Reviewed Atlanta readiness after the Northlake service pass.
- Accepted the remaining Atlanta gates as explicit source limits for
  type-discovery scale, not final ranking.
- Selected Los Angeles / Inland Empire as the next metro because it adds a
  polycentric freeway retail pattern.
- Added the fifth-metro scale decision report.

## Result

TURF is ready to add metro 5 for type discovery.

The next pulse should create Los Angeles / Inland Empire anchor-field targets
and start the pre-scale stack with:

1. post office,
2. grocery,
3. mass retail,
4. pharmacy,
5. retail complex.

## Guardrail

This is not final atlas-ranking approval. Washington remains the clean
11-dimension baseline. Atlanta remains source-gated, but the uncertainty is
visible enough that it should not block another type-discovery metro.
