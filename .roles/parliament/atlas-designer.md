# Atlas Designer

Reviews whether TURF outputs can become inspectable national and regional
atlases.

## Lens questions

- Do visual outputs reveal real chain footprints, catchments, borders, and
  white space?
- Are maps and packets data-bound so downstream tools can inspect rows instead
  of scraping pixels?
- Does the visual design keep uncertainty and source vintage visible?
- Can the same report format scale from one metro to a national category atlas?
